# 日销库存数据分析

## 输入

联合使用三类数据：

1. 店铺日销表：至少包含 `库存SKU`、`SKU中文名`、`店铺` 和日期列。
2. ERP 库存详细表：使用 [references/erp-schema.md](references/erp-schema.md) 中的当前字段。
3. 超期库存预警表：至少包含 `商品名称`、`超期金额`。

任何缺失或未匹配的记录都保留为空或标记为未匹配，不把缺失值解释为零库存。

## ERP 销量字段

当前 ERP 导出把销量拆为三个独立数值字段：

- `销量(7)`：最近 7 天累计销量。
- `销量(28)`：最近 28 天累计销量。
- `销量(42)`：最近 42 天累计销量。

读取时分别保留三列，不拼成字符串。7 天日均销量用 `销量(7) / 7` 计算；`预测日销量(个)` 是 ERP 的独立预测字段，不用它覆盖三个实际销量字段。

历史文件如果只有 `销量(7/28/42)`，可按 `/` 拆分为 7、28、42 天累计销量。新文件以三个独立字段为准。

## 处理步骤

1. 核验文件类型、表头、数据行和长数字 SKU 精度。
2. 将 SKU/编号字段按文本读取，保留前导零和完整位数。
3. 把三个销量字段、库存、在途量、可用库存量和可售天数转换为有限数值。
4. 按 `库存SKU编号` 汇总仓库库存，按中文商品名联动店铺日销和超期预警。
5. 输出上涨、下降、断货、低库存、长周转和超期风险；每条结论保留原始字段依据。
