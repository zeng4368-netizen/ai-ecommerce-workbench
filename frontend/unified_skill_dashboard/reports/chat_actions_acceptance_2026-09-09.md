# 聊天建议 → 行动中心验收

## 实现

- 回复工具栏支持「加入行动中心」，选中文字可只加入部分建议；编辑并确认后创建候选。来源分析与查询依据由服务端读取，不额外消费模型额度。
- 返回已有任务实现重复点击幂等，不覆盖已保存进度；同一回复可分拆不同标题的多项行动。
- 聊天回复链接到行动；行动可回到来源回复、带着已保存方案继续追问、打开业务模块。当前版本的日销任务可进入商品档案。
- 行动 AI 提示词与布局均为具体步骤在前、验收与理由在后；尊重已有计划，缺资料时形成可完成的核查任务，不承诺虚假成效。
- 移除独立「数据版本与真实证据」卡片及「查看旧版进度」入口。附件归入执行记录，后续数据核查归入人工复盘；原数据库资料不删除。
- 行动卡片增加具体步骤摘要和来源标识，增加来源筛选；阶段表单按需展开。
- 拟方案期间任务被更新时，旧草案只保存在历史，不覆盖新编辑。
