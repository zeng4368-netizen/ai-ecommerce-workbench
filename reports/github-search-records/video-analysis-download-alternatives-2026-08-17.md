# CreatOK 替代方案开源项目搜索记录

- 日期：2026-08-17
- 目标：用开源项目替代 CreatOK，分别覆盖「无水印下载」和「视频脚本/分镜分析」

## 候选核对

| 项目 | Stars | 语言 | 许可证 | 用途 | 结论 |
| --- | --- | --- | --- | --- | --- |

| `SYSTRAN/faster-whisper` | 24,945 | Python | MIT | 高速语音转文字（带时间戳） | 采用，替代 CreatOK 字幕 |
| `Evil0ctal/Douyin_TikTok_Download_API` | 19,384 | Python | Apache-2.0 | 抖音/TikTok 解析下载 API | 备选，替代/补充 yt-dlp |

## 结论

- 下载：主用 `yt-dlp` + TikTok 登录 cookie；备用 `Douyin_TikTok_Download_API`
- 字幕/脚本：`faster-whisper` 本地转写，替代 CreatOK 的 transcript
- 分镜：`PySceneDetect` 本地检测，替代 CreatOK 的 vision scenes
- 标签/结构总结：用本地 LLM（如 Ollama + Qwen/Llama）对同一商品的大量字幕+分镜做归纳，动态生成标签和逻辑顺序，不写死

## 本机环境

- 无 NVIDIA GPU（无 nvidia-smi），faster-whisper 需 CPU 推理；短视频可接受，长视频较慢
- ffmpeg 已可用（imageio-ffmpeg 内置）

## 2026-08-17 补充：Edge cookie 读取失败（DPAPI/ABE）

- 现象：Edge 关闭后 `yt-dlp --cookies-from-browser edge` 报 `Failed to decrypt with DPAPI`（yt-dlp issue #10927）
- 原因：新版 Edge/Chrome 对 cookie 启用「应用绑定加密」（App-Bound Encryption, ABE），普通 DPAPI 解密失效
- 可行方案：
  - 浏览器扩展导出（推荐）：Cookie-Editor（Edge 扩展商店有）导出 Netscape 格式；或 Get cookies.txt LOCALLY（Chrome 商店）装进 Edge
  - 开源工具 `xiecat/Chrome-App-Bound-Encryption-Decryption`（GitHub）：用户态解密 ABE cookie，可作后续自动化集成参考
  - Firefox 登录 TikTok 后 `--cookies-from-browser firefox`（Firefox 不用 DPAPI/ABE）
