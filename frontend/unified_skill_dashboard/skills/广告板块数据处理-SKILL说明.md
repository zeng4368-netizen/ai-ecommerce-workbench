## 一、技能是什么

一个两步流水线技能，处理 TikTok Shop 马来站的店铺数据，把三份原始 Excel 变成两份可直接分析/汇报的汇总表：

```
┌─────────────────┐   ┌─────────────────┐   ┌─────────────────┐
│ 店编-商品链接.xlsx │   │ 月份-产品包.xlsx  │   │ 年/月/周-店编.xlsx │
│  (第3行是表头)    │   │  (第1行是表头)    │   │  (第1行是表头)    │
└────────┬────────┘   └────────┬────────┘   └────────┬────────┘
         └──────────┬──────────┘                     │
                    ▼                                ▼
         【步骤一】链接汇总.xlsx ──────────► 【步骤二】广告汇总.xlsx
          （每个商品一行）                  （Video 按视频、Product card 按商品汇总）
```

## 二、什么时候用

- 处理「广告板块」文件夹里的数据
- 需要生成「链接汇总」或「广告汇总」
- 处理 TikTok 广告数据、计算 CPA/ROI、做店铺广告周报
- 处理「商品链接」「产品包」相关 Excel

## 三、文件命名规则（必须遵守）

| 类型 | 命名 | 示例 | 表头位置 |
|---|---|---|---|
| 店铺链接 | `店编-商品链接.xlsx` | `MS0237-商品链接.xlsx` | 第 3 行（1-2 行英文表头，4-5 行必填/说明行） |
| 产品包 | `月份-产品包.xlsx` | `8月-产品包.xlsx` | 第 1 行 |
| 广告数据 | `年/月/周-店编.xlsx` | `2026年8月34周-MS0237.xlsx` | 第 1 行 |
| 输出-链接 | `链接汇总.xlsx` | — | 自动生成 |
| 输出-广告 | `广告汇总.xlsx` | — | 自动生成 |

多店铺文件自动合并；输出写入数据文件夹。

## 四、脚本清单与用法

技能目录 `scripts/` 下共 4 个文件：

| 脚本 | 作用 | 用法 |
|---|---|---|
| `process_links.py` | 步骤一：店铺链接 → 链接汇总 | `python process_links.py --folder "数据文件夹"` |
| `process_ads.py` | 步骤二：广告数据 → 广告汇总 | `python process_ads.py --folder "数据文件夹"` |
| `run_all.py` | 一键编排（先步骤一后步骤二） | `python run_all.py --folder "数据文件夹"` |
| `store_info.py` | 店铺映射表 + 汇率（配置） | 被上述脚本引用，无需单独运行 |

常用参数：
- `--folder`：数据文件夹路径（必用）
- `--product`：指定产品包文件路径（步骤一）
- `--links`：指定链接汇总路径（步骤二）
- `--output`：指定输出文件路径

运行前提：Python 已安装 `pandas`、`openpyxl`。

## 五、输出结构速览

### 链接汇总.xlsx（每商品一行，11 列）

`店编 / 商品 ID / 商品名称 / 类目 / SKU数 / 链接款名 / 链接标签 / 链接平均客单 / 链接平均成本 / 链接目标CPA / 是否新品`

### 广告汇总.xlsx（49 列，Video/Product 一行）

1. **前缀 13 列**：年 / 月 / 周 / 国家 / 店编 / 店名 / 初级 / 中级 / 储高 / CEO / 链接款名 / 链接标签 / 是否新品
2. **分析 10 列**：实际CPA(USD) / 链接目标CPA(USD) / CPA差异 / 平均点击率 / 平均转化率 / 点击率分级 / 转化率分级 / ROI / 分级 / 建议方案
3. **原广告文件 26 列**（中文表头，保持原始列序）

表头样式：深蓝底白字加粗；百分比列（点击率/转化率/观看率/平均点击率/平均转化率）为 Excel 百分比格式 0.00%。

> **表头固定 v1.0**：49 列表头已固定（列名/顺序/类型不再修改），配套规范见《广告汇总表头规范.md》与《广告汇总表头规范.json》（网页搭建可直接引用）；新字段只能末尾追加并升级版本号。

## 六、配置位置（scripts/store_info.py）

| 配置项 | 说明 | 当前值 |
|---|---|---|
| `STORE_INFO` | 店编 →（店名, 国家, 初级, 中级, 储高, CEO） | 8 个马来店铺 |
| `MYR_TO_USD` | 马币→美元汇率（**每月更新**） | 0.248（2026-08） |

其他可调常量：

| 位置 | 常量 | 说明 | 当前值 |

| process_links.py | `CPA_DIVISOR` | 目标CPA 除数 | 16 |
| process_ads.py | `ROI_OK / ROI_WATCH` | 分级阈值 | 16 / 8 |
| process_ads.py | `COST_FALLBACK` | ROI 默认成本 | 0.1 |
| process_ads.py | `RATE_TOL` | 分级容差 | 5% |
| process_ads.py | `BAD_STATUS` | 不符合投放状态判定 | 不符合条件 |
| process_ads.py | `HEADER_CN` | 表头中文化映射 | 20 列 |

## 七、注意事项

1. 链接文件第 3 行必须是中文表头；数据行=商品 ID 为纯数字的行。
2. 19 位数字 ID（商品ID/Product ID/Campaign ID/Video ID）必须按文本处理，否则 float 精度丢失导致匹配失败（脚本已内置）。
3. 部分 SKU 不在当月产品包中属正常现象，未匹配字段留空。
4. 输出文件若正被 Excel/WPS/腾讯文档打开，写入会报占用错误，先关闭再运行。
5. 修改含公式的 Excel（如产品包）时，务必用 pandas 静态化写回，不要用 openpyxl 直接改后保存（会清空公式缓存值）。
