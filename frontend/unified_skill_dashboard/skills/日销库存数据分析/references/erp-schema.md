# ERP 库存详细字段规范

以 2026-09-19 的马来 ERP 导出为当前结构。工作表名称为 `库存详细`，字段顺序如下：

1. 库存SKU编号
2. 商品状态
3. 活跃度
4. 是否新款
5. 一级目录
6. 二级目录
7. 三级目录
8. 一级品牌
9. 二级品牌
10. 采购员
11. 中文名称
12. 英文名称
13. 父级仓库
14. 仓库
15. 仓位
16. 销量(7)
17. 销量(28)
18. 销量(42)
19. 预测日销量(个)
20. 仓位库存
21. 当前可售天数
22. 在途量
23. 海外仓预调入量
24. 分仓调拨预调入量
25. 警戒量
26. 警戒天数
27. 未发货量
28. 分仓调拨未发货量
29. 可用库存量
30. 最后出库时间
31. 最后入库时间

工作台识别 ERP 所需的核心字段为：`库存SKU编号`、`中文名称`、`仓位库存`、`可用库存量`、`当前可售天数`、`销量(7)`、`销量(28)`、`销量(42)`。

兼容旧导出时，旧字段 `销量(7/28/42)` 仅作为三个销量字段的后备输入。
