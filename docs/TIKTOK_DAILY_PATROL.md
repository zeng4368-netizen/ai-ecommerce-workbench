# TikTok 日常巡检

2026-09-14 新增。网站入口：`/#tiktok-patrol`，左侧「TikTok 日常巡检」。

## 实际接入范围

复用现有六店绑定，各店的 ID、币种和时区独立。新增七组本地规则：销售复盘、库存预警、广告异常、履约风险、新增差评、店铺健康、通知待办。对应紫鸟案例库的 TikTok 晨会日报、昨日数据复盘、多店巡检、库存预警、绩效监控及异常汇总思路；不使用 Amazon FBA、A-to-Z 或 ODR 规则。

当前已实现报表模板、导入校验及预览、手动巡检、阈值记录、异常优先级过滤、原始文件下载、报告下载和店铺历史。用户要求多店巡检后，已核验六店的昨日销售概览、昨日 GMV Max 广告概览及当前首页待办/库存/健康提醒，并增加每日曲线、日期范围和全部店铺批次。七个模块的 SKU 明细巡检仍使用报表导入。

## 操作流程

1. 选择单店，展开「导入报表 · SKU 级巡检」，选择报表业务日期。顶部日期范围用于查询已保存的每日趋势，不改变导入表的单日校验。
2. 下载 XLSX 模板。阅读「填写说明」，将对应真实数据填入模块工作表。暂时没有的模块保持空表，不能把未知值填零。
3. 导入后核对店铺、日期、币种、时区、行数及样本。
4. 调整规则阈值，点击「确认数据并生成巡检」。只运行本地规则，不调用模型、不操作店铺。
5. 查看异常及来源行，下载报告或原始表格。每次运行新建记录，历史不覆盖；该店下次载入沿用其最近一次已运行阈值。

模板不是 TikTok 任意原始导出的通用解析器。表头严格校验，未经验证的别名不自动映射。每表按一个固定粒度填写，不能混入汇总与组成明细；同表对象 ID 唯一。日期、币种、店铺及所有必要字段不一致时拒绝导入。模板不含演示业务值。

## 新指标口径

- 销量环比：选定日销量相对前日销量；前日为零时不计算百分比。
- 可售天数：可售库存除以近七日均销量；近七日无销量时显示不可计算，仍检查库存件数。
- 广告 ROAS：同一归因口径的收入除以广告花费；不是利润 ROI。零花费和低于评估门槛的计划不做 ROAS 预警。
- 超时履约：使用已在平台核实的超时待发货数，不自行假设各站点 SLA。
- 差评：仅同一业务日的商品低星评价数，不与店铺 Feedback、绩效分数混算。
- 健康及通知：只根据填报的未处理违规、未读和紧急通知提示待办，不代表完成合规审查。

本模块独立命名、独立计算，不改变原 Skill 的算法、字段或历史分析。覆盖七个模块也只说明导入资料覆盖了七类，不能证明全店采集完整；页面始终显示范围说明。当天尚未结束时，报告额外标注部分数据。

## 持久化与安全

- 新增 SQLite 表 `tiktok_patrol_sources`、`tiktok_patrol_runs`，不变更已有业务表和数据 head。
- 原始输入：`data/raw/ai_workbench/tiktok_patrol/<source_id>/source.xlsx`。
- 报告及日志：`data/output/ai_workbench/tiktok_patrol/<run_id>/`，包含 JSON、Markdown、run.log。
- 每次保存 SHA256、对象来源行、阈值、规则版本和店铺身份。原始报表下载再次校验哈希。
- 未创建任何定时计划，没有新增外部模型调用、平台写入或任意 CLI 执行接口。
- 文件大小、解压大小及每表行数受限；数值需有限且非负，数量为整数。缺失、重复 ID、跨店数据及不可能的计数关系会被拒绝。

## 实时接入与边界

已增加用户要求的全部店铺入口。选择「全部店铺」后点击「巡检全部店铺」；单店按钮为「开始一次只读巡检」。只读运行在后台执行，页面显示进度和已完成部分；不自动调度，刷新页面也不会自动采集。

所有新选择器放在 `config/selectors.yaml` 的 `tiktok_patrol_live`，按六店绑定配置 MY/TH 域名、店铺身份、广告账号、页面指标及日期控件；`store_profiles` 为逐店覆盖项，不能继承别家店的广告账号。运行经服务端 Bridge 白名单调用官方 CLI；不读取 Cookie、个人 profile 或隐藏接口。只点击已核验的日期筛选控件，不点击广告修改、权限申请批准或业务处理按钮。

昨日销售以 MYR 展示；广告账户以 USD 展示，平台 ROI 原值单独保留，不视为利润率。销售与广告的 SKU 订单数及变化率保留各自口径，不强行对账为同一指标。首页“紧急”不转换成超时订单，差评总数不转换成昨日新增差评，低库存提醒数量不转换成可售件数。

增加 `tiktok_patrol_live_runs`、`tiktok_patrol_live_batches` 和共享 `ziniao_browser_lease`，与原账单导出互斥。租约过期的运行显示已中断，不自动恢复。保留已读取部分；身份、登录、验证码、日期、币种、广告账号或指标集合不符均暂停。通过唯一运行 ID 保存证据、报告和日志，不激活或覆盖旧数据版本。

实时证据位于 `data/raw/ai_workbench/tiktok_patrol_live/<run_id>/`，报告与日志位于 `data/output/ai_workbench/tiktok_patrol_live/<run_id>/`。截图位于 `data/screenshots/ai_workbench/tiktok_patrol_live/<run_id>/`。CLI 实际返回临时截图路径，程序在校验路径和 PNG 签名后复制至归档；不能仅因 CLI 成功就宣称目标文件存在。

进一步接入 SKU 全量库存、广告计划明细、昨日新增评价或站内信前，仍须独立核验真实字段、分页与范围。当前实现不声称这些明细已接通。
