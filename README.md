## 原 Excel 分析工具

这是一个本地运行的 Excel 分析原型，用于把销售、结算、控价/成本/库存、超期库存四类表格合并成产品经营报告。

## 启动

```powershell
python app.py
```

启动后打开：

```text
http://127.0.0.1:5000
```

如果需要让同一个局域网/Wi-Fi 下的其他电脑访问，启动后让对方打开：

```text
http://你的本机局域网IP:5000
```

例如：

```text
http://192.168.1.23:5000
```

默认服务会监听 `0.0.0.0:5000`，允许局域网访问。如果只想本机访问，可以这样启动：

```powershell
$env:HOST="127.0.0.1"; python app.py
```

如果其他电脑打不开，通常是 Windows 防火墙拦截了 5000 端口，需要允许 Python 或 TCP 5000 入站。

## 数据表

页面支持上传 4 类 Excel：

- 销售数据表：订单、SKU、销量、销售额、店铺、类目
- 结算收入表：TikTok Shop 结算、退款、佣金、手续费、运费
- 控价/成本/库存表：SKU 成本、价格档位、库存、SKU 状态
- 超期库存表：超期库存、超期金额、周转天数、出清目标

如果不上传，工具会默认使用当前目录里识别到的这 4 个文件。

## 当前输出

- 月度核心指标
- 店铺表现
- COD / 非 COD 分析
- 品类销售和毛利
- SKU 销售额、成本、标价利润、到账利润
- 产品日销分析和每日销量明细
- 饼图和条形图可视化分析
- 低标价利润或亏损 SKU
- 零金额/疑似样品赠品成本占用
- 部分订单的到账利润
- 高库存和库存紧张 SKU
- 超期库存产品和品类
- 控价调整原因和明细

报告页只展示每张表前 20 行，完整结果会导出到 `reports/` 目录下的 Excel 报告。

## 筛选功能

生成报告后，可以在报告页顶部筛选：

- 店铺
- SKU（下拉选择）
- 产品关键词
- 一级类目
- 二级类目
- 三级类目

点击“应用筛选”后，系统会基于同一批上传文件重新计算指标，并生成一份新的当前筛选结果 Excel 报告。点击“清空筛选”可恢复全量数据。

筛选会同步影响销售、毛利、日销、结算匹配、库存、超期、控价等板块。页面中的表格会显示完整数据，表格区域内可以向下滚动查看剩余行。

报告页会生成图表分析，包括店铺销售额排名、SKU 销售额 Top、产品日均销量 Top、每日销量走势、COD 占比、品类销售额占比和超期金额占比。图表同样会随筛选条件自动更新。

每个表格模块也有独立的 Excel 式操作：

- 本表搜索
- 每列下拉筛选
- 点击表头升序/降序排序
- 重置当前表
- 导出当前筛选后的 CSV

顶部筛选用于重算整份报告；表格内筛选只影响当前模块，适合临时查找和排序。

## 重要口径

- 销售分析默认排除状态为 `已作废` 的订单。
- 成本统一使用 `2026-06-控价 (1).xlsx` 的 `6月产品包` sheet 中的 `销售成本国家币`。
- 成本统一使用 `销售成本国家币`，按 `商品数量 * 销售成本国家币` 汇总。
- 标价利润按 `(标价收入 - 货品成本) / 标价收入` 计算，标价收入来自结算表 `总收入`。
- 到账利润按 `(到账收入 - 货品成本 - 退包成本) / 到账收入` 计算，到账收入来自结算表 `结算总金额`。
- 去除邮局按 `(到账收入 - 货品成本 + 退包成本) / 到账收入` 计算。
- 退货退款占比按 `-(退包成本 + 退款金额 + 退款成本) / 到账收入` 计算；当前四表没有独立退款成本源时，会用已匹配退款订单的货品成本估算。
- 商品金额为 0 且有数量/成本的行会被标记为疑似样品、赠品或配件成本占用。
