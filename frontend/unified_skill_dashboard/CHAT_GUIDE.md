# AI 聊天工作区

2026-09-09：替换旧「报告 + 单次提问」界面，保留 DeepSeek 服务端配置和原 Skill 计算逻辑。

## 使用

本地打开 `http://127.0.0.1:8765/#assistant`。

- 左侧新聊天、搜索，右侧持续对话；支持重命名、Markdown 导出、回收站与恢复。
- Enter 发送，Shift + Enter 换行，中文输入法确认文字不触发发送；支持代码块及复制。
- 同一聊天传递全部已成功完成的轮次，不同聊天不共享上下文。草稿存在当前浏览器的会话存储，消息存在本地 SQLite，刷新/重启后可继续。
- 「读取工作台数据」开启时按需调用现有只读查询工具，不强迫普通问题查业务表，也不固定输出报告。关闭后禁止本轮读取工作台；之前聊天中已有的业务内容不会因此被抹去。
- 查数回复保留版本和可展开的工具证据。切换数据批次后重新查数，不把历史回答当作当前数据。
- 停止生成保留已返回内容；失败可以重试最后一条问题，不重复添加提问。中途切换页面时后台继续保存回复，重新进入可读取状态。
- 旧分析审计原文不删除；已有对话保留，孤立分析迁入独立历史聊天。

## 真实能力与限制

这是类似 GPT 的聊天交互，底层仍是所配置的 DeepSeek，不是 ChatGPT 服务。当前没有联网搜索、语音、聊天附件解析或聊天内生图。内容工作室仍为单独模块。

使用真实供应商 SSE 分段返回内容，不使用假打字动画；思考字段不显示。未配置/超时/供应商错误不会冒充成功。

聊天记录没有四轮截断；输入保护上限为序列化消息 120,000 字符（不是 token），本轮工具证据累计保护为 180,000 字符。超限明确提示新建聊天/导出，完整旧记录保留，不宣称无限上下文。各次模型输出仍沿用服务端上限，达到上限显示不完整提醒。

停止请求在供应商下一段响应或网络超时后生效，已产生费用无法撤销。不进行无人确认的业务操作。密钥只在服务端，只有发送消息时调用模型；访问历史和测试不会消费真实模型额度。

## 聊天建议与行动联动（2026-09-09）

每条成功回复下可点「加入行动中心」。可先选中某一段建议，弹窗中编辑行动标题、对象、模块、步骤及可选负责人/期限，确认后只创建待复核候选，不自动批准。普通聊天没有业务证据时会明确作为建议保存，不能据此声称已验证业务事实。

同一回复、模块、对象和标题重复加入只返回已有任务，不覆盖原进度。一个回复的多条建议可分别设置标题加入。导入不再次调用模型；拟定行动方案仍由用户点击后调用原 DeepSeek 接口。

聊天回复有「查看行动」入口；行动详情支持「返回来源聊天」「继续问 AI」。后者带入任务的已保存方案供继续讨论，不自动发送问题。日销规则任务在当前版本匹配时可直接查看商品档案。

行动方案的展示和提示词均改为：具体动作 → 验收产物 → 为什么这样做 → 指标/边界。执行记录与附件、人工复盘按阶段展开。移除旧版进度入口和独立的数据版本证据卡片，数据库审计、原证据及附件不删除。

新增 `/api/actions/from-analysis`：只接受已保存分析的来源 ID 和用户编辑字段，从服务端取原回复及依据，要求明确确认；不允许客户端伪造来源证据或提交执行状态。

聊天建议目前没有自动映射到原风险规则，后续效果检查明确显示待人工复核，不假称自动复算完成。
